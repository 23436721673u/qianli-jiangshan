# 千里江山图 · 入画

一个在浏览器里游览《千里江山图》式青绿山水的 3D 小游戏。整个游戏就是一个 `index.html`，不用安装、不用联网，双击就能打开。

## 玩法

- **自由漫游**：飞越绵延 4.6 公里的江流与群山，沿途有村落、长桥、亭台和行舟。
- **寻印**：江山间散落着十二方朱印，远处能看到朱色光柱，飞近就能收入卷中，进度会自动保存。
- **月夜**：一键入夜，夜空有星河和明月，山脉上的金线发光，江水泛起微光，村落亮起灯火。
- **北冥之鲲**：一条巨鲲在群峰上空巡游。飞近后可以骑上鲲背，跟着它遨游全图。
- **放灯祈愿**：放一盏孔明灯，看它缓缓升入夜空。
- **画卷留影**：把当前画面存成图片，并自动加上题款和朱印。
- **舆图**：右上角的小地图会显示你、巨鲲和朱印的位置，点击任意一处即可飞过去。
- **手势入画**：开启摄像头后，可以用手势控制视角。识别在本地完成，画面不会上传。

## 操作

| 按键 | 作用 |
| --- | --- |
| 鼠标移动 / 点击画面锁定 | 环视 |
| W A S D / 方向键 | 移动 |
| E / Q | 上升 / 下降 |
| Shift | 加速 |
| N | 昼夜切换 |
| B | 乘鲲 / 下鲲（需先飞到巨鲲 90 米以内） |
| L | 放灯 |
| P | 留影 |
| M | 开关舆图 |
| H | 隐藏界面 |
| R | 回到起点视角 |
| F | 全屏 |

## 运行

- **本地运行**：下载 `index.html`，用 Chrome 或 Edge 打开即可。
- **在线访问**：在仓库的 Settings → Pages 中，把 Source 设为 `Deploy from a branch`，分支选 `main`，目录选 `/ (root)`。稍等几分钟，就能通过 `https://<用户名>.github.io/<仓库名>/` 访问。手势功能需要 HTTPS 才能调用摄像头，Pages 地址正好满足这一要求。

需要一块支持 WebGL2 的显卡。如果画面卡顿，可以在「意境」设置里调低画质。
